Lua code assistant

Type a task in Russian or English. The system will plan the approach, generate Lua 5.5 code, validate it (syntax + runtime), and self-correct if something is wrong. It may ask a clarifying question if the task is ambiguous. Follow-up messages refine the previous code.

Examples: "Return the last email from wf.vars.emails", "Просуммируй wf.vars.items", then "add nil check"
